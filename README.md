## design-editor

基于 `fabric.js` 和 `Vue3` 的图像编辑器，支持自定义字体、素材和设计模板。

### [预览](http://47.104.0.129/)

## 功能

- 图片编辑 ✅
- 图片裁剪 ✅
- 图层及顺序调整 ✅
- 撤销/重做 ✅
- 外观属性/字体属性/描边/阴影 ✅
- 自定义字体 ✅
- 快捷键（鼠标缩放） ✅
- 右键菜单 ✅
- 辅助线 ✅
- 图层对齐参考线 ✅
- 标尺 ✅
- 图片替换
- 图片滤镜 ✅
- 画布自定义调整 ✅
- 导入、导出模板 ✅
- 生成图片 ✅

## 启动

```js
npm i
npm run dev
```

## 打包

```js
npm run build
```
